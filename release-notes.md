Плагин JOSM «Сетевые магазины» 0.2.0.

Сверяет магазины сетей (Магнит, М.Косметик, Пятёрочка, К&Б, Wildberries,
Ригла, Ярче!, Мария-Ра) с данными OSM в загруженной области: показывает,
чего нет, и где расходятся теги (часы, название, оператор, адрес). Каждый
объект разбирается отдельно, на сервер OSM плагин ничего не загружает.

Что нового в 0.2.0:

- добавлены сети «Ярче!» и «Мария-Ра» (адреса, координаты, часы работы);
- кэш списков сетей и кнопка «Кэш» для его очистки;
- значки сетей на карте, включаются отдельной кнопкой;
- меню сортировки: по статусу, по сети, по типу и без сортировки,
  с выбором направления;
- выровнены размеры значков в панели и на карте;
- обновлены теги новых сетей (name:ru/en, brand:ru/en);
- обновлены README и скриншоты.

Установка: скачать архив для своей системы, закрыть JOSM и запустить
install.ps1 (Windows) или install.sh (macOS, Linux). Либо взять chainpoi.jar
и положить в папку plugins JOSM, добавив <entry value='chainpoi'/> в список
plugins в preferences.xml.

Требования: JOSM и Java 17+.
Подробности: https://github.com/Glebzilla/josm-chainpoi
