# Букмарклеты: данные сетей из браузера

Часть сайтов не отдаёт данные обычному HTTP-клиенту: у них JS-челлендж
(5ka.ru — Servicepipe) или антибот (Wildberries — Qrator). Поэтому плагин
не лезет на эти сайты сам, а читает **выгрузку, которую сделал ваш браузер**.

## Формат файла

```json
{
  "chain": "pyaterochka",
  "points": [
    {
      "lat": 45.3677,
      "lon": 40.7093,
      "address": "ул. Ленинградская, 20",
      "code": "77",
      "tags": {
        "shop": "supermarket",
        "name": "Пятёрочка",
        "brand": "Пятёрочка",
        "brand:wikidata": "Q1768969",
        "opening_hours": "Mo-Su 08:00-23:00"
      }
    }
  ]
}
```

`chain` — идентификатор сети: `magnit`, `magnit-kosmetik`, `pyaterochka`,
`ozon`, `ozon-box`, `wildberries`. `tags` — теги, с которыми плагин будет
сравнивать и создавать объекты.

## Пятёрочка

1. Откройте <https://5ka.ru/stores/> и дождитесь карты.
2. Выполните [`pyaterochka.js`](pyaterochka.js) — закладкой или в консоли.
3. Получится `chainpoi-pyaterochka.json`.
4. В JOSM: **Данные → Проверить сетевые магазины**, кнопка **Из файла…**.
   Загружаются точки в видимой области (с запасом), чтобы не сверять тысячи
   объектов сразу.

## Ozon и Wildberries

Готовых букмарклетов пока нет: их карты используют закрытые эндпоинты, которых
я не видел. Если пришлёте образец ответа (DevTools → Network → ответ с точками),
добавлю букмарклет и разбор. Со стороны плагина всё готово: профили `ozon`,
`ozon-box` и `wildberries` уже есть, файл читается.

## Правовое

Данные берутся с сайта сети для проверки её же магазинов. Из Яндекс.Карт
разрешены только фотографии панорам — подложку и спутник использовать нельзя.
